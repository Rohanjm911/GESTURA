# 🖐️ GESTURA
### Control Beyond Touch.

**GESTURA** is a gesture-controlled Windows desktop application that allows users to interact with their PC using hand movements captured through a webcam.

Transform your hands into a virtual mouse and experience a new way of controlling your computer.

---

## ✨ Features

- 🖱️ Gesture-based mouse control
- 👆 Left-click, right-click and double-click
- ✋ Drag and drop
- 🔄 Gesture-based scrolling
- 🤚 One-hand and two-hand tracking
- 🔊 System volume control
- 💡 Screen brightness control
- 🎵 Media playback controls
- 🎯 Real-time hand tracking
- ⚙️ Customizable gesture settings
- 📷 Live webcam preview

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core development |
| OpenCV | Computer vision |
| MediaPipe | Hand tracking |
| PySide6 | Desktop interface |
| PyAutoGUI | Mouse and keyboard control |
| Windows APIs | System-level operations |
| JSON | Configuration management |

## 🖥️ Platform

- Windows 10 / Windows 11
- Built-in or external webcam
- Python-based application

## 🔒 Privacy

GESTURA is designed with a privacy-first approach.

- Local webcam processing.
- No cloud-based hand tracking.
- No webcam recording.
- No unnecessary data collection.

## 🚀 Project Goals

The primary goal of GESTURA is to create a smooth, responsive, and customizable touch-free computer interaction experience.

Future development will focus on improving gesture recognition, reducing latency, expanding gesture customization, and introducing additional system controls.
